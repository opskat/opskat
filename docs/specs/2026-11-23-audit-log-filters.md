# 审计日志筛选与审计页 UI/UX 重构

> Status: Approved
> Owner: OpsKat 维护者
> Last updated: 2026-11-23

**Objective:** 让用户在审计页按关键字、来源、工具、资产（多选 / 按分组）、结果、决策与决策方组合筛选审计记录，并把审计页的详情查看、分页、加载反馈、会话授权汇总与连接池展示整理成一致可用的界面；`opsctl list audit` 提供同一套筛选。

**Hard invariant:** 审计记录的写入路径与已存数据不变（不迁移、不改字段含义）；现有的会话筛选、时间范围筛选、模型审核展示、加载失败不落入空态（`AsyncState` 错误块 + 重试）行为保持。

## Problem

1. **只能按会话和时间筛选。** 审计页顶栏只有会话下拉与时间范围（`frontend/src/components/audit/AuditLogPage.tsx` 顶栏），后端 `ListAuditLogs` 只接受 source / assetID / 时间 / sessionID 且前端恒传空 source 与 0 资产（同文件 `loadLogs`）。本机库 211,583 条审计中 209,727 条来自 opsctl、203,958 条是 `exec`（2026-11-23 只读查询实测），找某台资产、某类被拒绝的操作只能逐页翻。
2. **详情是模态对话框。** 行尾 ⓘ 打开 `Dialog`，看下一条要先关闭再点；请求 JSON 原样一行显示，没有复制入口。
3. **分页只有上一页 / 下一页。** 页码无法跳转，每页固定 20 条，21 万条数据下无法定位。
4. **换筛选 / 翻页时没有可辨认的加载反馈。** 旧行原样留着、只有刷新图标在转，用户分不清当前看到的是不是新结果。
5. **会话「已允许模式」汇总只统计当前页。** `sessionApprovedPatterns` 从当前页 `logs` 里聚合 `grant_submit`，翻页后汇总内容随之变化，会话的授权超过一页时显示不全。
6. **连接池只显示数字 asset_id。** 连接池表第一列是 `entry.asset_id`，用户要自己对照资产 ID。
7. **`opsctl list audit` 只能按资产筛选。** 只有 `--asset` 与 `--limit`（`cmd/opsctl/command/list.go`），与桌面端能力不一致。

## Actors and user stories

1. 作为运维人员，我想按资产（含整组资产）、工具、关键字快速收窄审计记录，以便追查某台机器上发生过什么。
2. 作为审批负责人，我想只看被拒绝的、或由某一方（策略 / 用户 / 授权 / Autopilot 等）做出决定的操作，以便复核审批策略。
3. 作为排障者，我想在不离开列表的情况下连续浏览多条记录的详情并复制命令 / 请求 / 输出。
4. 作为脚本或终端用户，我想用 `opsctl list audit` 以同样的条件查询审计。

## Design decisions

| # | Decision | Basis and rejected option |
|---|---|---|
| 1 | 布局采用**表头筛选**（方案 C）：来源 / 工具 / 资产 / 决策 / 结果的筛选入口在各自列头；关键字、会话、时间范围留在顶栏；已生效条件以标签行汇总 | 用户在三版 mockup 对比后选定（user-decided）。Rejected: 方案 A「搜索 + 筛选弹层」— 条件入口离列远；方案 B「常驻筛选栏」— 1120 宽已换行，720 宽占两行半 |
| 2 | 「结果」列只显示图标，表头只留筛选图标；命令列弹性宽度；同年时间省略年份 | 保证 720 宽主区域内整表不横向滚动（user-decided，mockup 实测） |
| 3 | 决策拆成「放行 / 拒绝」与「决策方」两个可组合维度 | 用户指出决策还分谁做的决定（user-decided）。决策方由已有 `decision_source` 归组得出 |
| 4 | 决策方归组：策略、用户、授权、辅助审批、Autopilot、执行前拦截（全部 `exec_*`）、批量执行（全部 `batch_*`）、无需审批（`decision_source` 为空） | 不合并时选项超过 15 个且多数无数据；行内标签仍显示细分原因（user-confirmed 未提异议）。归组定义只在后端一处，桌面端与 opsctl 共用。Rejected: 前端自行映射 — 会与 CLI 各写一份 |
| 5 | 资产筛选可多选、可按分组勾选，复用现有资产多选树；已删除资产经点击表格单元格加入 | 用户要求多选与选组（user-decided）。Rejected: 选项取审计表中出现过的资产 — 无法按分组选 |
| 6 | 选项来源：来源、结果、放行/拒绝固定；工具与决策方取当前时间范围内实际出现的值；会话沿用现有按时间范围列出；资产取当前资产树 | 工具是开放集合（本机 44 种，含已改名旧工具与扩展工具），写死必漏；决策方只列有数据的项避免选了查不到。实测近 1 天去重 < 1 ms、全量 21 万条约 0.1–0.5 s（user-confirmed） |
| 7 | 工具、来源、决策方单选；只有资产多选 | 界面简单；用户未要求其它维度多选（user-confirmed） |
| 8 | 详情改为表格右侧浮层抽屉（非模态），点整行打开，↑ / ↓ 切换，Esc 关闭；窄窗口时抽屉覆盖表格右侧大部分 | 用户选定（user-decided）。Rejected: 宽窗口挤压并排 — 用户接受浮层方案 |
| 9 | 筛选状态不跨关闭 / 重启保留，每次打开为默认「近 1 天、无筛选、第 1 页、每页 20 条」 | 用户未选「跨重开保留」（user-decided） |
| 10 | 审计页拆分为筛选栏、表格、详情抽屉、分页、连接池与数据加载 hook | 现单文件 694 行承担全部职责；本次改动覆盖每一块，按 SRP 拆开是在改动范围内的重构（verified） |

## 筛选

### 顶栏

- 关键字搜索框：对**命令**与**资产名**做不区分大小写的子串匹配；输入停止约 300 ms 后查询；`%`、`_` 等字符按字面匹配，不作通配。清空按钮清除关键字。
- 会话下拉：行为与现状一致（按时间范围列出会话，分今天 / 昨天 / 本周 / 更早）。
- 时间范围：行为与现状一致（全部、1h、3h、6h、1d、7d、自定义起止）。

### 表头筛选

每个可筛选列头在列名后显示漏斗图标；条件生效时图标为实心主色。点击图标弹出该列的选项：

- **来源**：全部 / opsctl / AI / 桌面端，单选，选后关闭。
- **工具**：全部 + 当前时间范围内出现过的工具名（等宽字体），单选，选后关闭。
- **资产**：带搜索（含拼音）的资产树复选列表；勾选分组即选中组内全部资产，部分选中时分组为半选。勾选结果按当时的资产 ID 集合查询，之后新加入该组的资产不会自动纳入。
- **决策**：上部「全部 / 放行 / 拒绝」；下部「决策方」单选列表，只列当前时间范围内出现过的决策方分组。两者可同时生效。
- **结果**：全部 / 成功 / 失败。列头无文字，悬停提示「结果」。

任一条件变化后回到第 1 页。工具 / 决策方选项获取失败时，对应弹层显示错误与重试，不影响列表本身。

### 已生效条件标签行

顶栏下方列出所有非默认条件（会话、来源、工具、资产、结果、决策、决策方），每个可单独移除；末尾「清空」一次移除全部（时间范围不受影响）。资产标签显示前两个名称，超过时追加「等 N 个」。无条件时整行不显示。

### 点击单元格加条件

表格中的来源、工具、资产名、决策标签、结果图标可点击，悬停显示虚下划线与「按此筛选」提示：

- 来源 / 工具 / 结果：替换该维度的当前值。
- 资产名：追加到资产多选集合（已在集合中则不变）；已删除的资产同样可加入，标签显示审计记录里的资产名。
- 决策标签：同时设置放行/拒绝与该记录所属的决策方分组。

点击这些元素只加条件，不打开详情。

### 空结果

有条件且结果为空时显示「没有符合筛选条件的记录」与「清空筛选」按钮；无条件时沿用现有空态文案。加载失败沿用 `AsyncState` 错误块与重试，不落入空态。

## 表格

列顺序：时间、来源、工具、资产、命令、决策、结果。

- 时间：与当前年份相同时显示 `MM/DD HH:mm:ss`，否则带年份；悬停显示完整时间。
- 来源：新增列，显示 opsctl / AI / 桌面端。
- 命令：占用剩余宽度，超出部分截断，悬停显示全文；无命令显示「-」。
- 决策：沿用现有决策方标签与模型审核标记；无决策显示「-」。
- 结果：成功 / 失败图标；失败时悬停显示错误摘要。
- 行尾 ⓘ 按钮移除，整行可点击打开详情；打开详情的行高亮。

在 720 px 宽的主区域内，表格不出现横向滚动。

## 详情抽屉

- 点击行（非可筛选元素处）在表格区域右侧打开约 440 px 宽、最多占表格区 85% 的浮层面板；表格仍可滚动与点击，点击其它行切换详情。
- 标题栏：结果图标、工具名、资产名；上一条 / 下一条 / 关闭按钮。键盘 ↑ / ↓ 在当前页内切换（焦点在输入框内时不响应），到达本页首尾时对应按钮禁用；Esc 关闭。翻页、筛选变化后若所选记录不在新结果中则关闭抽屉。
- 元信息：时间（完整）、来源、资产、决策（放行/拒绝 + 决策方）、匹配规则（有则显示）、模型审核（有则显示，沿用现有审核展示）、会话 ID（可复制）。来源、资产、会话可点击加为筛选条件。
- 内容块按顺序：命令、错误（红色底）、请求（JSON 可解析时格式化缩进显示，否则原样）、输出；空块不显示。每块右上角有复制按钮，复制成功走 `notifyCopied`。
- 所有文本可选中复制。

## 分页

底栏左侧显示「第 a–b 条 · 共 N 条」（千分位）；右侧依次为每页条数（20 / 50 / 100）、首页、上一页、页码输入框（回车或失焦跳转，越界钳到首末页）、`/ 总页数`、下一页、末页。加载中翻页按钮禁用。更换每页条数回到第 1 页。顶栏不再显示总数。

## 加载反馈

筛选、翻页、刷新触发的查询进行中：已显示的行保留但半透明且不可点击，表头下方显示不确定进度条，刷新图标旋转。首次加载且无数据时显示居中加载态（沿用 `AsyncState`）。查询结果返回顺序以最后一次发起的查询为准，较早发起、较晚返回的结果不覆盖当前结果。

## 会话授权汇总

选中会话时，表格上方显示「此会话已授权的命令模式」及条数，内容为该会话**全部** `grant_submit` 记录（按资产分别列出模式），与当前页、其它筛选条件无关。该会话无授权记录时不显示。获取失败时该区域显示错误与重试，不影响列表。

## 连接池

资产列显示资产类型图标、资产名与 `#ID`；资产已不存在时显示「已删除的资产 #ID」。其余列与刷新行为不变。

## opsctl list audit

在现有 `--asset`、`--limit` 之外新增，与桌面端同义：

| 参数 | 含义 |
|---|---|
| `--asset <ref>` | 可重复，多个资产取并集（名称、组/名称或数字 ID） |
| `--source <ai\|opsctl\|desktop>` | 来源 |
| `--tool <name>` | 工具名 |
| `--result <success\|failed>` | 结果 |
| `--decision <allow\|deny>` | 放行 / 拒绝 |
| `--decider <policy\|user\|grant\|assisted\|autopilot\|exec_gate\|batch\|none>` | 决策方分组 |
| `--session <id>` | 会话 ID |
| `--grep <text>` | 命令或资产名子串，不区分大小写，按字面匹配 |
| `--since <duration>` | 只看最近一段时间，接受 `30m`、`6h`、`7d` 形式 |

非法枚举值或无法解析的时长以非零退出并在 stderr 说明可选值；输出格式、排序、默认条数不变。使用说明与示例同步更新。

## 兼容与边界

- 不新增迁移、不改审计表结构；已有索引之外的查询（关键字、工具、决策方）为全范围扫描，在默认「近 1 天」范围内可忽略，「全部」范围实测约 0.1–0.5 s，可接受。
- 未知的 `decision_source` 值（未来新增、尚未归组）不出现在决策方选项中；行内标签仍原样显示。
- 文案提供 zh-CN 与 en，各用地道表达。
- 键盘：表头漏斗、标签移除、分页控件、抽屉按钮均可 Tab 聚焦并有可见焦点；图标按钮带可读标签。

## Out of scope

- 筛选状态持久化、URL 化、保存常用筛选。
- 工具 / 来源 / 决策方多选；按分组动态（随分组成员变化）筛选。
- 导出、自动刷新 / 新记录提示、按日期分组显示。
- 其它页面的分页组件统一（`MongoDBResultView` 等保持原样）。
- AI 工具侧的审计查询能力。
